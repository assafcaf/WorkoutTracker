Home: the first screen, in five moments

Four blocks, each a picture first and a number second: today (the week's ring and the one workout to do), lifts (14 trend lines, one dot of colour each), sessions (twelve weeks of the A/B calendar) and last time. Every block opens the tab where its detail lives. One ink bar, docked. Tabs: Home · Progress · Sessions · Program (Train becomes the workout page Home opens). Data: scripts/render-states/stats-45.json, read at each state's clock.
