Ledger & Instrument: one trainee, eight phases, six screens

Lists read like a training ledger: rows on paper, hairlines, no cards. The set screen is an instrument: one number you can read from the bench. Ink is the action; colour only ever means something: blue is now, green is better, rust is lower, gold is a record, and teal/plum name Workout A/B on the calendar.
